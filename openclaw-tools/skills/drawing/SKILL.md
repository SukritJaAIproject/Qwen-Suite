# /drawing - ตรวจแบบวงจรไฟฟ้า

ผู้ใช้ระบุไฟล์แบบ (PDF) หรือส่วนที่ต้องการตรวจต่อจาก /drawing อ่านแบบด้วย `local_read` action `inspect_project_document` {"project", "path_alias", "relative_path"} ถ้าอ่านข้อความในแบบไม่ได้ให้บอกตรง ๆ ห้ามเดา

เช็กลิสต์ (บทเรียนจากการตรวจแบบตู้ชาร์จ B781001) ตรวจทีละแผ่น
1. กรอบชื่อแบบและ revision: เลขแบบและเวอร์ชันในกรอบตรงกับชื่อไฟล์ ตาราง revision มีวันที่และรายการแก้ แผ่นที่เขียนว่า inferred หรือไม่ใช่ as-built ให้แยกไว้ ไม่ใช้เป็นหลัก
2. เลขสายและเลขขั้ว: สายทุกเส้นมีเลขทั้งสองปลาย เลขขั้วมีอยู่จริงบนอุปกรณ์ tag ตรงกับสัญลักษณ์ (เช่น เลขรีเลย์ใน tag เลื่อนจากสัญลักษณ์)
3. cross-reference ระหว่างแผ่น: สัญญาณเดียวกันต้องไปจุดเดียวกันทุกแผ่น (เช่น แผ่นหนึ่งเป็น COM อีกแผ่นเป็น NO, พัดลมรับไฟจากคนละรีเลย์หรือคนละแหล่งจ่าย)
4. สายสื่อสาร: TX ต้องไปเข้า RX (ไขว้) ตรวจกับ pinout ใน datasheet ของอุปกรณ์จริง RS-485 A/B ไม่สลับกับ tag CAN H/L และตัวต้านทานปลายสาย
5. แหล่งจ่ายและกราวด์: แรงดันคอยล์และแหล่งจ่ายตรงกันทุกแผ่น 0 V ของแต่ละแหล่งจ่ายเชื่อมกันเมื่อวงจรต้องใช้ทางกลับร่วม
6. การป้องกัน: ฟิวส์หรือเบรกเกอร์เทียบขนาดสาย SPD มีฟิวส์สำรอง E-stop ตัดวงจรด้วยฮาร์ดแวร์ ไม่ใช่แค่ส่งสัญญาณให้คอนโทรลเลอร์ ปลดเบรกเกอร์หลักแล้วไฟหมดทั้งตู้จริงไหม
7. การต่อในแบบ: จุดต่อรูปตัว T มีจุด junction ปลายสายไม่ขาดก่อนถึงขา (ดูเหมือนต่อแต่ netlist ไม่ต่อ)
8. การวัด: ขั้ว shunt จุดแท็ปแรงดันของมิเตอร์ และช่องคอนโทรลเลอร์ตรงกับหัวชาร์จที่ถูกต้อง

กติกา
