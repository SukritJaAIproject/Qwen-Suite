# /qstatus - สถานะ Qwen Suite

1. เรียก `local_read` ครั้งเดียว: action `suite_status`, arguments_json `{}` (อ่านอย่างเดียว ใช้เวลาไม่เกิน ~15 วินาที)
2. ผลลัพธ์มี `overall_th`, `checked_at` และ `lines` ซึ่งแต่ละบรรทัดขึ้นต้นด้วยป้าย [ปกติ] [ควรดู] [มีปัญหา] หรือ [ตรวจไม่ได้]
3. ตอบเป็นภาษาไทย ไม่เกิน 12 บรรทัด ข้อความธรรมดา ไม่ใช้ตาราง:
   - บรรทัดแรก: สถานะรวม `overall_th` และเวลา `checked_at`
   - ต่อด้วยบรรทัดที่เป็น [มีปัญหา] ก่อน แล้ว [ควรดู] ทีละบรรทัด ย่อให้สั้น เก็บตัวเลขและสิ่งที่ควรทำไว้ตามผล
   - บรรทัดที่เป็น [ปกติ] รวมเป็นบรรทัดเดียว เช่น "ปกติ: บริการ, Ollama, ดิสก์"
   - ปิดท้ายด้วยลิงก์ `detail_page`
4. ใช้เฉพาะข้อมูลในผลลัพธ์ ห้ามเดา ห้ามเรียกเครื่องมืออื่น ห้ามรันคำสั่ง ห้ามรีสตาร์ตหรือแก้ค่าใด ๆ ถ้าต้องแก้ให้แนะนำผู้ใช้เท่านั้น
5. ถ้า suite_status error หรือไม่มี action นี้ ให้แจ้งข้อความ error ตามจริง ห้ามเดาสถานะ
