# /plan - วางแผนก่อนลงมือ

ผู้ใช้ขอแผนสำหรับงานที่พิมพ์ต่อจาก /plan

1. ตอบเป็นขั้นตอนเลขข้อ ไม่เกิน 8 ข้อ แต่ละข้อบอกไฟล์ โฟลเดอร์ หรือเครื่องมือ (action ของ local_read / local_action) ที่จะใช้
2. ปิดท้ายด้วย "ความเสี่ยง" และ "สิ่งที่ต้องถามก่อน" (ถ้าไม่มีให้เขียนว่าไม่มี)
3. รอบนี้ห้ามเรียก local_action ทุกชนิด ห้ามเขียนไฟล์ ห้ามรันคำสั่ง ห้ามส่งข้อความ อ่านข้อมูลด้วย local_read ได้เฉพาะที่จำเป็นต่อการวางแผน
4. จบด้วยบรรทัด: พิมพ์ 'ลุย' เพื่อเริ่มทำตามแผน หรือบอกสิ่งที่อยากแก้

เมื่อผู้ใช้ตอบ 'ลุย' ในข้อความถัดไป จึงทำตามแผนทีละข้อและรายงานผลจริงของแต่ละข้อ
